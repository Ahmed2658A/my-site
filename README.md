# ELCAYSAR STORE 👑 — Full System Starter

هذه بداية النسخة الكاملة للنظام وليست منصة إنتاج مكتملة بعد.

## الموجود الآن
- واجهة Marketplace شاملة.
- أقسام ألعاب/إلكترونيات/موبايلات/ملابس/منزل/بطاقات.
- سلة مشتريات.
- نموذج طلب.
- واجهة حساب عميل.
- Backend Node.js/Express كبداية.
- API health endpoint.
- هيكل واضح لتسجيل الدخول، المنتجات، الطلبات، الكوبونات وPaymob.

## الخطوة التالية
ربط قاعدة بيانات حقيقية + نظام Auth + Admin Dashboard + إدارة المنتجات والمخزون والطلبات والكوبونات + الشحن + Paymob.

## أمان
لا تضع Paymob Secret Key أو أي بيانات سرية في frontend.
